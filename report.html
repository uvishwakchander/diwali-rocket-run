📋 Executive Summary

Diwali Rocket Run is an interactive 3D browser game created for Diwali celebrations. Built with Three.js (WebGL), HTML5, and the Web Audio API, the game delivers an authentic 350 km flight journey starting from CDC2 Chennai along the NH48 Golden Quadrilateral corridor and concluding with a grand celebration at BDC14 Bangalore.

🌐 GitHub Pages Deployment Guide

To publish the game live to https://uvishwakchander.github.io/diwali-rocket-run/:

# 1. Initialize and commit
git init
git add .
git commit -m "Deploy: Diwali Rocket Run 3D Game"

# 2. Push to GitHub
git branch -M main
git remote add origin https://github.com/uvishwakchander/diwali-rocket-run.git
git push -u origin main --force

Then open Repository Settings ➔ Pages, select branch main, and click Save. The site will be live at:
👉 https://uvishwakchander.github.io/diwali-rocket-run/
